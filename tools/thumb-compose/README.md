# 대표 이미지 합성 도구 (사이트에는 쓰이지 않음)

원본 스크린샷을 잘라 다크 배경(#111214 + 오른쪽 위 청록 빛 + 노이즈) 위에 합성해 2560×1440 대표 이미지를 만든다. 화면 픽셀은 바꾸지 않는다.

```
python3 comp.py <스크린샷 폴더> <출력.jpg> mockup|collage
```

- `mockup`: 브라우저 창 2개(뒤: 목록, 앞: 상세)를 겹침
- `collage`: 핵심 UI 조각(레이어 · 팝업 · 상태 목록)을 카드처럼 띄워 배치
- 현재 좌표·파일명은 공동구매(groupbuying) 기준. 다른 프로젝트는 `mode` 분기에 crop 좌표를 추가해서 사용.
- 필요: Python 3, Pillow, NumPy
- 규격: 가운데 1440×1440 안에 핵심, 하단 25%는 비움 (Works 카드 제목이 겹침)
